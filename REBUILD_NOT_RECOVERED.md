# ProofFlow Rebuild — Not Recovered

This branch contains a reconstruction of ProofFlow from the surviving repository documentation and the available AccountabilityEcosystem frontend artifact.

It is **not** a recovery of the lost managed-project source.

The existing bootstrap history remains the provenance record. Reconstructed code must be reviewed, tested, and explicitly identified as reconstructed before any production designation.

## Reconstruction boundary

Recovered directly from GitHub: repository documentation, accountability principles, and bootstrap history.

Available implementation artifact: `AccountabilityEcosystem.tsx`, supplied separately as a source artifact. It provides UI structure and validation concepts but does not establish the original managed project's complete source, configuration, database, hosting, or Stripe setup.

## Non-negotiable provenance rule

Never describe reconstructed code as the original application. The release record must identify the reconstruction commit and separately identify anything verified against the original managed environment.
